# ОП11 — Безопасность жизнедеятельности
## Программа подготовки к промежуточной аттестации

---

### Требования
- Python 3.6 или выше (без дополнительных библиотек)

---

### Запуск

**Windows:**
```
python exam.py
```

**Linux / macOS:**
```
python3 exam.py
```

---

### Режимы тестирования

| Режим | Описание |
|-------|----------|
| **1** | От 1 до N — случайный порядок вопросов с 1 по N |
| **2** | От N до M — случайный порядок вопросов с N по M |
| **3** | 50 вопросов начиная с N (или до конца, если вопросов меньше 50) |

---

### Как пользоваться

1. Запустите `exam.py`
2. Выберите режим
3. Введите параметры диапазона
4. Отвечайте на вопросы: вводите букву варианта ответа (`а`, `б`, `в`, ...)
   - Если вопрос допускает несколько ответов — введите буквы через пробел или запятую
5. После каждого ответа увидите результат
6. В конце — итоговая статистика и разбор ошибок

---

### Структура файлов

```
exam_prep/

```
